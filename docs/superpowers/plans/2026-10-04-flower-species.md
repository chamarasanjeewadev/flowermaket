# Flower Species & Variants Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hardcoded `flower-catalog.ts` static file with a DB-backed `flower_species` + `flower_variants` table that all pages read from and admins can manage.

**Architecture:** Two new Drizzle tables (`flower_species`, `flower_variants`) replace `apps/web/src/lib/flower-catalog.ts`. A new `packages/api/src/repos/flowers.ts` provides query functions consumed by three web pages and two new admin routes. `products` gains a nullable `flower_variant_id` FK. Image assets move to a Supabase Storage bucket `flower-images`.

**Tech Stack:** Drizzle ORM, Supabase Postgres + Storage, TanStack Start server functions, Vitest

**Spec:** `docs/superpowers/specs/2026-10-04-flower-species-design.md`

## Global Constraints

- All DB access via Drizzle — no raw SQL strings except in migration files
- `getEnv()` / `createDb()` / `tryCreateDb()` called inside request handlers only — never at module top level
- Schema imports: `import { schema } from "@flowers/db/client"` (not the barrel `@flowers/db`)
- `Db` type: `import type { Db } from "../db"` inside `packages/api/src/repos/`
- `flower_species.id` and `flower_variants.id` are `text` slugs (not UUIDs)
- Money never stored as float; flowers have no price column
- Display name rule: `"{colorEn} {speciesNameEn}"` when `colorEn` non-null, else `"{speciesNameEn}"`
- Cloudflare Workers: `{ max: 1, prepare: false }` on postgres client (already enforced by `createDb()`)
- No `any`, no untyped SQL

## Review Focus

- **Empty `/en/design` after migration:** `listDesignerVariants` returns only variants with a linked active product. Since `flowerVariantId` is null on all existing products, the bouquet picker will be empty until a supplier or admin links products to variants. Task 8 must add a fallback that shows all active variants when zero linked variants exist, so the page doesn't break.
- **Quotation builder price lookup:** The old name-match hack is removed; auto-pricing from a listing now requires `product.flowerVariantId === variant.id`. If no products are linked, `unitPrice` falls back to `0` (user enters manually). Task 7 tests this fallback explicitly.
- **Null `colorEn`:** Flowers like Lotus and Baby's Breath have `colorEn = null`. `variantDisplayName` must not produce `"null Lotus"`. Task 3 tests this path.
- **Missing image:** 21 of 29 variants seed with `imagePath = null`. `FlowerShowcase` must render `/placeholder-flower.svg` without breaking layout. Task 5 tests this path.
- **RLS blocks admin writes:** If the admin RLS policy is wrong, `upsertFlowerSpecies` will silently return 0 rows rather than throw. Task 2 must verify by running the insert as an anon user (should fail) and as admin (should succeed) after migration.

export const flowerVariants = pgTable(
  "flower_variants",

    colorSi: text("color_si"),

-- RLS for flower_species
ALTER TABLE public.flower_species ENABLE ROW LEVEL SECURITY;

CREATE POLICY "public_read_active_flower_species"
  ON public.flower_species
  FOR SELECT
  USING (is_active = true);

CREATE POLICY "admin_manage_flower_species"
  ON public.flower_species
  FOR ALL
  USING (
    EXISTS (
      SELECT 1 FROM public.users
      WHERE id = auth.uid() AND role = 'admin'

import { DESIGNER_CATEGORY_SLUGS } from "../constants";
import type { Db } from "../db";

// ---------------------------------------------------------------------------
// Exported types
// ---------------------------------------------------------------------------

export type FlowerVariantRow = {
  id: string;
  speciesId: string;
  colorEn: string | null;
  colorSi: string | null;
  imagePath: string | null;
  /** Full Supabase Storage public URL, or null if no image uploaded yet. */
  imageUrl: string | null;
  isFeatured: boolean;
  isActive: boolean;
  sortOrder: number;
  // joined from flower_species
  nameEn: string;
  nameSi: string;
  localName: string | null;

  id: string;
  nameEn: string;
  nameSi: string;
  localName: string | null;
  category: "imported" | "tropical" | "local";
  defaultUnit: "stem" | "bunch" | "arrangement" | "item";
  sortOrder: number;
  isActive: boolean;
  variants: Array<{
    id: string;
    colorEn: string | null;

    imagePath: string | null;

  defaultUnit: "stem" | "bunch" | "arrangement" | "item";
  sortOrder?: number;
  isActive?: boolean;
};

export type UpsertVariantInput = {
  id: string;
  speciesId: string;
  colorEn?: string | null;
  colorSi?: string | null;
  imagePath?: string | null;
  isFeatured?: boolean;
  isActive?: boolean;
  sortOrder?: number;
};

// ---------------------------------------------------------------------------
// Helpers
// ---------------------------------------------------------------------------

export function variantDisplayName(
  v: Pick<FlowerVariantRow, "colorEn" | "colorSi" | "nameEn" | "nameSi">,
  locale: "en" | "si",
): string {
  if (locale === "si") {
    const color = v.colorSi ?? v.colorEn;
    return color ? `${color} ${v.nameSi}` : v.nameSi;
  }
  return v.colorEn ? `${v.colorEn} ${v.nameEn}` : v.nameEn;
}

function flowerImageUrl(imagePath: string | null, supabaseUrl: string): string | null {
  if (!imagePath) return null;
  return `${supabaseUrl}/storage/v1/object/public/flower-images/${imagePath}`;
}

// ---------------------------------------------------------------------------
// Shared select shape — keeps column lists DRY
// ---------------------------------------------------------------------------

const variantSelect = {
  id: schema.flowerVariants.id,
  speciesId: schema.flowerVariants.speciesId,
  colorEn: schema.flowerVariants.colorEn,
  colorSi: schema.flowerVariants.colorSi,
  imagePath: schema.flowerVariants.imagePath,
  isFeatured: schema.flowerVariants.isFeatured,
  isActive: schema.flowerVariants.isActive,
  sortOrder: schema.flowerVariants.sortOrder,
  nameEn: schema.flowerSpecies.nameEn,
  nameSi: schema.flowerSpecies.nameSi,
  localName: schema.flowerSpecies.localName,
  category: schema.flowerSpecies.category,
  defaultUnit: schema.flowerSpecies.defaultUnit,
} as const;

function attachImageUrl(
  rows: Omit<FlowerVariantRow, "imageUrl">[],
  supabaseUrl: string,
): FlowerVariantRow[] {
  return rows.map((r) => ({ ...r, imageUrl: flowerImageUrl(r.imagePath, supabaseUrl) }));
}

// ---------------------------------------------------------------------------
// Public queries
// ---------------------------------------------------------------------------

export async function listFlowerVariants(
  db: Db,
  supabaseUrl: string,
): Promise<FlowerVariantRow[]> {
  const rows = await db
    .select(variantSelect)
    .from(schema.flowerVariants)
    .innerJoin(
      schema.flowerSpecies,
      eq(schema.flowerVariants.speciesId, schema.flowerSpecies.id),
    )
    .where(
      and(
        eq(schema.flowerVariants.isActive, true),
        eq(schema.flowerSpecies.isActive, true),
      ),
    )
    .orderBy(asc(schema.flowerVariants.sortOrder));
  return attachImageUrl(rows, supabaseUrl);
}

export async function listFeaturedVariants(
  db: Db,
  supabaseUrl: string,
): Promise<FlowerVariantRow[]> {
  const rows = await db
    .select(variantSelect)
    .from(schema.flowerVariants)
    .innerJoin(
      schema.flowerSpecies,
      eq(schema.flowerVariants.speciesId, schema.flowerSpecies.id),
    )
    .where(
      and(
        eq(schema.flowerVariants.isActive, true),
        eq(schema.flowerVariants.isFeatured, true),
        eq(schema.flowerSpecies.isActive, true),
      ),
    )
    .orderBy(asc(schema.flowerVariants.sortOrder));
  return attachImageUrl(rows, supabaseUrl);
}

export async function listDesignerVariants(
  db: Db,
  supabaseUrl: string,
): Promise<FlowerVariantRow[]> {
  // Step 1: find variant IDs linked to active designer-category products
  const linked = await db
    .selectDistinct({ variantId: schema.products.flowerVariantId })
    .from(schema.products)
    .innerJoin(
      schema.categories,
      eq(schema.products.categoryId, schema.categories.id),
    )
    .where(
      and(
        eq(schema.products.status, "active"),
        inArray(schema.categories.slug, [...DESIGNER_CATEGORY_SLUGS]),
        isNotNull(schema.products.flowerVariantId),
      ),
    );

  const variantIds = linked
    .map((r) => r.variantId)
    .filter((id): id is string => id !== null);

  // Fallback: if no products are linked yet, return all active variants so
  // the /en/design page is not an empty screen during the migration period.
  const whereClause =
    variantIds.length > 0
      ? and(
          eq(schema.flowerVariants.isActive, true),
          eq(schema.flowerSpecies.isActive, true),
          inArray(schema.flowerVariants.id, variantIds),
        )
      : and(
          eq(schema.flowerVariants.isActive, true),
          eq(schema.flowerSpecies.isActive, true),
        );

  const rows = await db
    .select(variantSelect)
    .from(schema.flowerVariants)
    .innerJoin(
      schema.flowerSpecies,
      eq(schema.flowerVariants.speciesId, schema.flowerSpecies.id),
    )
    .where(whereClause)
    .orderBy(asc(schema.flowerVariants.sortOrder));
  return attachImageUrl(rows, supabaseUrl);
}

// ---------------------------------------------------------------------------
// Admin queries
// ---------------------------------------------------------------------------

export async function listAdminSpeciesWithVariants(
  db: Db,
  supabaseUrl: string,
): Promise<FlowerSpeciesWithVariants[]> {
  const [species, variants] = await Promise.all([
    db
      .select()
      .from(schema.flowerSpecies)
      .orderBy(asc(schema.flowerSpecies.sortOrder)),
    db
      .select()
      .from(schema.flowerVariants)
      .orderBy(asc(schema.flowerVariants.sortOrder)),
  ]);

  const variantsBySpecies = new Map<string, typeof variants>();
  for (const v of variants) {
    if (!variantsBySpecies.has(v.speciesId)) {
      variantsBySpecies.set(v.speciesId, []);
    }
    variantsBySpecies.get(v.speciesId)!.push(v);
  }

  return species.map((s) => ({
    ...s,
    variants: (variantsBySpecies.get(s.id) ?? []).map((v) => ({
      ...v,
      imageUrl: flowerImageUrl(v.imagePath, supabaseUrl),
    })),
  }));
}

export async function upsertFlowerSpecies(
  db: Db,
  data: UpsertSpeciesInput,
): Promise<void> {
  await db
    .insert(schema.flowerSpecies)
    .values({
      id: data.id,
      nameEn: data.nameEn,
      nameSi: data.nameSi,
      localName: data.localName ?? null,
      category: data.category,
      defaultUnit: data.defaultUnit,
      sortOrder: data.sortOrder ?? 0,
      isActive: data.isActive ?? true,
    })
    .onConflictDoUpdate({
      target: schema.flowerSpecies.id,
      set: {
        nameEn: data.nameEn,
        nameSi: data.nameSi,
        localName: data.localName ?? null,
        category: data.category,
        defaultUnit: data.defaultUnit,
        sortOrder: data.sortOrder ?? 0,
        isActive: data.isActive ?? true,
      },
    });
}

        colorSi: data.colorSi ?? null,
        imagePath: data.imagePath ?? null,
        isFeatured: data.isFeatured ?? false,

    });
}

```tsx
import type { FlowerVariantRow } from "@flowers/api/repos/flowers";
import { variantDisplayName } from "@flowers/api/repos/flowers";
import type { Locale } from "../../i18n/types";

interface FlowerShowcaseProps {
  flowers: FlowerVariantRow[];
  locale: Locale;
  ctaLabel?: string;
  onEnquire?: (flower: FlowerVariantRow) => void;
  getHref?: (flower: FlowerVariantRow) => string;
}

export function FlowerShowcase({
  flowers,
  locale,
  ctaLabel = "Enquire →",
  onEnquire,
  getHref,
}: FlowerShowcaseProps) {
  return (
    <ul className="grid grid-cols-2 gap-x-6 gap-y-10 sm:grid-cols-3 lg:grid-cols-4">
      {flowers.map((flower) => {
        const name = variantDisplayName(flower, locale);
        const href = getHref?.(flower);
        return (
          <li key={flower.id} className="flex flex-col">
            <div className="aspect-square w-full overflow-hidden">
              {flower.imageUrl ? (
                <img
                  src={flower.imageUrl}
                  alt={name}
                  className="h-full w-full object-contain"
                  loading="lazy"
                />
              ) : (
                <img
                  src="/placeholder-flower.svg"
                  alt={name}
                  className="h-full w-full object-contain opacity-40"
                />
              )}
            </div>
            <span className="mt-3 font-display text-lg font-bold leading-snug">
              {name}
            </span>
            <span className="mt-0.5 text-sm text-muted-foreground">
              Fresh bouquet arrangement
            </span>
            {href ? (
              <a
                href={href}
                className="mt-2 text-sm font-medium text-brand hover:underline"
              >
                {ctaLabel}
              </a>
            ) : onEnquire ? (
              <button
                type="button"
                onClick={() => onEnquire(flower)}
                className="mt-2 text-left text-sm font-medium text-brand hover:underline"
              >
                {ctaLabel}
              </button>
            ) : null}
          </li>
        );
      })}
    </ul>
  );
}
```

```ts
import { createServerFn } from "@tanstack/start";
import { createDb, getEnv } from "@flowers/api";
import {
  listAdminSpeciesWithVariants,
  upsertFlowerSpecies,
  upsertFlowerVariant,
  type UpsertSpeciesInput,
  type UpsertVariantInput,
} from "@flowers/api";
import { createSupabaseServerClient } from "@flowers/auth";
import { resolveAdminSession } from "./session";

function requireAdmin() {
  // Throws if not admin — call at start of every server function
  return resolveAdminSession().then((session) => {
    if (session.kind !== "admin" && session.kind !== "auth_disabled") {
      throw new Error("Forbidden");
    }
  });
}

export const getAdminFlowers = createServerFn({ method: "GET" }).handler(
  async () => {
    await requireAdmin();
    const { DATABASE_URL, SUPABASE_URL } = getEnv();
    const db = createDb(DATABASE_URL);
    return listAdminSpeciesWithVariants(db, SUPABASE_URL);
  },
);

export const saveFlowerSpecies = createServerFn({ method: "POST" })
  .validator((d: UpsertSpeciesInput) => d)
  .handler(async ({ data }) => {
    await requireAdmin();
    const { DATABASE_URL } = getEnv();
    const db = createDb(DATABASE_URL);
    await upsertFlowerSpecies(db, data);
  });

export const saveFlowerVariant = createServerFn({ method: "POST" })
  .validator((d: UpsertVariantInput) => d)
  .handler(async ({ data }) => {
    await requireAdmin();
    const { DATABASE_URL } = getEnv();
    const db = createDb(DATABASE_URL);
    await upsertFlowerVariant(db, data);
  });

export const uploadVariantImage = createServerFn({ method: "POST" })
  .validator(
    (d: { variantId: string; base64: string; mimeType: string; filename: string }) => d,
  )
  .handler(async ({ data }) => {
    await requireAdmin();
    const { DATABASE_URL } = getEnv();
    const db = createDb(DATABASE_URL);
    const supabase = createSupabaseServerClient();
    if (!supabase) throw new Error("Supabase not configured");

    // Decode base64 → Uint8Array
    const binary = atob(data.base64);
    const bytes = new Uint8Array(binary.length);
    for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);

    const ext = data.filename.split(".").pop() ?? "webp";
    const path = `flowers/${data.variantId}.${ext}`;

    const { error } = await supabase.storage
      .from("flower-images")
      .upload(path, bytes, { contentType: data.mimeType, upsert: true });

    if (error) throw new Error(`Storage upload failed: ${error.message}`);

    await upsertFlowerVariant(db, { id: data.variantId, speciesId: "" /* no-op for patch */ });
    // Patch only imagePath — use a direct update:
    const { createDb: makeDb } = await import("@flowers/api");
    const db2 = makeDb(DATABASE_URL);
    const { schema } = await import("@flowers/db/client");
    const { eq } = await import("drizzle-orm");
    await db2
      .update(schema.flowerVariants)
      .set({ imagePath: path })
      .where(eq(schema.flowerVariants.id, data.variantId));

    return { imagePath: path };
  });
```

- [ ] **Step 1: Create `apps/admin/src/routes/flowers.$speciesId.tsx`**

```tsx
import { createFileRoute } from "@tanstack/react-router";
import React from "react";
import { getAdminFlowers, saveFlowerVariant, uploadVariantImage } from "../server/flowers";
import type { FlowerSpeciesWithVariants } from "@flowers/api";

export const Route = createFileRoute("/flowers/$speciesId")({
  loader: async ({ params }) => {
    const all = await getAdminFlowers() as FlowerSpeciesWithVariants[];
    const species = all.find((s) => s.id === params.speciesId);
    if (!species) throw new Error("Species not found");
    return { species };
  },
  component: VariantPage,
});

function VariantPage() {
  const { species } = Route.useLoaderData() as { species: FlowerSpeciesWithVariants };
  const [showAdd, setShowAdd] = React.useState(false);
  const [saving, setSaving] = React.useState(false);
  const [uploadingId, setUploadingId] = React.useState<string | null>(null);
  const [form, setForm] = React.useState({
    id: "", colorEn: "", colorSi: "", sortOrder: 0, isFeatured: false,
  });

  async function handleSaveVariant(e: React.FormEvent) {
    e.preventDefault();
    setSaving(true);
    try {
      await saveFlowerVariant({
        data: {
          id: form.id,
          speciesId: species.id,
          colorEn: form.colorEn || null,
          colorSi: form.colorSi || null,
          sortOrder: form.sortOrder,
          isFeatured: form.isFeatured,
          isActive: true,
        },
      });
      window.location.reload();
    } finally {
      setSaving(false);
    }
  }

  async function handleImageUpload(variantId: string, file: File) {
    setUploadingId(variantId);
    try {
      const reader = new FileReader();
      const base64 = await new Promise<string>((resolve, reject) => {
        reader.onload = () => resolve((reader.result as string).split(",")[1]);
        reader.onerror = reject;
        reader.readAsDataURL(file);
      });
      await uploadVariantImage({
        data: { variantId, base64, mimeType: file.type, filename: file.name },
      });
      window.location.reload();
    } finally {
      setUploadingId(null);
    }
  }

  return (
    <div className="p-6">
      <a href="/flowers" className="mb-4 inline-block text-sm text-brand hover:underline">
        ← Back to Species
      </a>
      <h1 className="mb-2 text-2xl font-bold">{species.nameEn}</h1>
      <p className="mb-6 text-sm text-muted-foreground">
        {species.nameSi} · {species.category} · default unit: {species.defaultUnit}
        {species.localName ? ` · ${species.localName}` : ""}
      </p>

      <div className="mb-6 flex items-center justify-between">
        <h2 className="text-lg font-semibold">Variants</h2>
        <button type="button" onClick={() => setShowAdd((v) => !v)} className="rounded bg-brand px-4 py-2 text-sm text-white">
          {showAdd ? "Cancel" : "Add Variant"}
        </button>
      </div>

      {showAdd && (
        <form onSubmit={handleSaveVariant} className="mb-8 grid grid-cols-2 gap-4 rounded border p-4">
          <label className="flex flex-col gap-1 text-sm">
            ID (slug, e.g. "red-rose")
            <input required value={form.id} onChange={(e) => setForm({ ...form, id: e.target.value })} className="rounded border px-2 py-1" />
          </label>
          <label className="flex flex-col gap-1 text-sm">
            Color (English, optional)
            <input value={form.colorEn} onChange={(e) => setForm({ ...form, colorEn: e.target.value })} placeholder="e.g. Red" className="rounded border px-2 py-1" />
          </label>
          <label className="flex flex-col gap-1 text-sm">
            Color (Sinhala, optional)
            <input value={form.colorSi} onChange={(e) => setForm({ ...form, colorSi: e.target.value })} placeholder="e.g. රතු" className="rounded border px-2 py-1" />
          </label>
          <label className="flex flex-col gap-1 text-sm">
            Sort Order
            <input type="number" value={form.sortOrder} onChange={(e) => setForm({ ...form, sortOrder: parseInt(e.target.value) || 0 })} className="rounded border px-2 py-1" />
          </label>
          <label className="flex items-center gap-2 text-sm">
            <input type="checkbox" checked={form.isFeatured} onChange={(e) => setForm({ ...form, isFeatured: e.target.checked })} />
            Featured (show in fresh-flowers showcase)
          </label>
          <div className="col-span-2">
            <button type="submit" disabled={saving} className="rounded bg-brand px-4 py-2 text-sm text-white disabled:opacity-50">
              {saving ? "Saving…" : "Save Variant"}
            </button>
          </div>
        </form>
      )}

      <div className="grid grid-cols-2 gap-4 sm:grid-cols-3 lg:grid-cols-4">
        {species.variants.map((v) => {
          const displayName = v.colorEn
            ? `${v.colorEn} ${species.nameEn}`
            : species.nameEn;
          return (
            <div key={v.id} className="rounded border p-3">
              <div className="aspect-square w-full overflow-hidden rounded bg-muted">
                {v.imageUrl ? (
                  <img src={v.imageUrl} alt={displayName} className="h-full w-full object-contain" />
                ) : (
                  <div className="flex h-full items-center justify-center text-xs text-muted-foreground">
                    No image
                  </div>
                )}
              </div>
              <p className="mt-2 text-sm font-medium">{displayName}</p>
              <p className="text-xs text-muted-foreground">
                {v.isFeatured ? "★ Featured" : "Not featured"} · {v.isActive ? "Active" : "Inactive"}
              </p>
              <label className="mt-2 flex cursor-pointer items-center gap-1 text-xs text-brand">
                {uploadingId === v.id ? "Uploading…" : "Upload image"}
                <input
                  type="file"
                  accept="image/*"
                  className="sr-only"
                  disabled={uploadingId !== null}
                  onChange={(e) => {
                    const file = e.target.files?.[0];
                    if (file) handleImageUpload(v.id, file);
                  }}
                />
              </label>
            </div>
          );
        })}
      </div>
    </div>
  );
}
```
